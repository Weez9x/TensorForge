# TensorForge

TensorForge — учебный проект на C++20 о высокопроизводительных вычислениях на CPU. Сейчас в проекте изучается умножение матриц: от простой реализации до вариантов с улучшенным доступом к памяти и многопоточностью.

## Реализовано

- Класс `Matrix` с построчным хранением данных в одном `std::vector<float>`.
- Проверка совместимости размеров матриц перед умножением.
- Три последовательных алгоритма:
  - **IJK** — циклы в порядке `i → j → k`;
  - **IKJ** — циклы в порядке `i → k → j`;
  - **Blocked** — блочное умножение с настраиваемым размером блока.
- **Parallel IKJ** — параллельное умножение, в котором потоки обрабатывают разные строки результата.
- Тесты для проверки размеров и значений результатов, обработки некорректных входных данных и сравнения алгоритмов.

## Сборка и запуск

Нужны C++20-компилятор и CMake версии 3.20 или новее.

Сборка и запуск примера:

```bash
cmake -S . -B build/debug -DCMAKE_BUILD_TYPE=Debug
cmake --build build/debug
./build/debug/tensorforge
```

## Тесты

```bash
ctest --test-dir build/debug --output-on-failure
```

Тесты сравнивают результаты реализаций с обычным умножением IJK и проверяют обработку несовместимых размеров, нулевого размера блока и нулевого числа потоков.

## Бенчмарк

Собрать и запустить бенчмарк в Release:

```bash
cmake -S . -B build-release -DCMAKE_BUILD_TYPE=Release
cmake --build build-release
./build-release/matmul_benchmark
```

Бенчмарк сравнивает IJK, IKJ, блочный алгоритм с размерами блока 32 и 64, а также параллельный IKJ с 1, 2, 4 и 8 потоками. Проверяются квадратные матрицы размером 128, 256, 512 и 1024.

Для каждого алгоритма выполняется один прогревочный запуск и пять измеряемых. В таблице показывается среднее время в миллисекундах. В замер входит полный вызов функции умножения, включая создание и обнуление матрицы результата; заполнение входных матриц и печать таблицы не измеряются.

Входные матрицы заполнены единицами, поэтому значение элемента `(0, 0)` результата должно быть равно размеру матрицы. Бенчмарк выводит контрольную сумму этого элемента для прогревочного и пяти измеряемых запусков. Полная проверка результатов выполняется отдельными тестами.

## Дальнейшие планы

Проект развивается постепенно: сначала проверяются корректность и производительность CPU-алгоритмов, затем можно изучать SIMD и обобщать вычисления на тензоры. Более дальние направления — CUDA и компоненты для inference runtime.
